# PowerShell Automation Suite

A collection of production-ready PowerShell scripts for system administration, log analysis, and automated reporting.

## Projects
- **System Health Reporter**: Collects CPU, RAM, Disk, and Service status.
- **Log Sniper**: Parses massive log files with date filters and exports to HTML/CSV.
- **Backup Tool**: Compresses folders, archives, and enforces retention policies.
- **Daily Maintenance Suite**: Combines all three into a single automated HTML dashboard with email delivery.

## Why This Matters
- **100% Automation**: Reduces daily admin tasks from 2 hours to 0.
- **Secure**: Uses Windows encrypted credentials for email delivery.
- **Production Ready**: Scheduled to run daily via Task Scheduler.
- **Professional Reporting**: HTML dashboards for management visibility.

## Technologies Used
- PowerShell 5.1+
- Windows CIM/WMI
- SMTP Email Integration
- Windows Task Scheduler
