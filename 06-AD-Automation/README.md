# Active Directory Automation Scripts

## Overview
This collection demonstrates real-world PowerShell automation for Active Directory environments—everything from bulk user creation to security health checks.

## Scripts

### 1. ADHealth.ps1
- Displays Domain Controller status, replication health, and user/computer counts.
- Gives a quick, visual health snapshot of your domain.

### 2. Bulk-User-Generator.ps1
- Creates 20+ test users in the `Corp_Users` OU in under 3 seconds.
- Demonstrates automated user provisioning with secure password handling.

### 3. User-Health-Checker.ps1
- Identifies locked-out and disabled user accounts.
- Counts total active users.
- Critical for daily security and administrative audits.

## Environment
- Windows Server 2022
- Active Directory Domain Services
- PowerShell 5.1+
